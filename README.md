This repository contains the public reader-facing release of *The Architecture of the Liminal* and its philosophical companion essay. The project is a literary-philosophical threshold work about the interval before action: the moment in which a hand, institution, platform, machine, wound, metric, or symbolic frame can become motion before review, judgment, or consequence has returned.

## What is included

The repository is organized into two main reading routes.

### Heavy reader

`heavy_reader/full_codex__the_architecture_of_the_liminal.md`  
`heavy_reader/full_codex__the_architecture_of_the_liminal.pdf`

This is the full literary-philosophical Codex. It works through mythic, somatic, machine-facing, and archival registers. Its symbolic figures are literary devices and pattern-names, not claims of spiritual authority, literal cosmology, executable code, or institutional representation.

### Academic companion

`academic/philarchive_companion_essay__reconstructive_threshold_philosophy.md`  
`academic/philarchive_companion_essay__reconstructive_threshold_philosophy.pdf`

This essay translates the Codex's main pressure into analytic philosophical terms. It presents Reconstructive Threshold Philosophy as a regulative framework for the interval before action. Its single distinctive move is the re-entrant audit of the corrective itself: the requirement that any brake, method, helper, founding name, guardrail, AI assistant, institution, or text be tested for whether it has become the capture it was meant to prevent.

## Reading order

Start with `WHAT_THIS_WORK_IS_FOR.md` if you need the shortest orientation.

Read the essay first if you want the analytic framework, literature positioning, and philosophical claims.

Read the Full Codex first if you want the literary architecture, mythic/somatic registers, and full pressure of the work.

The two texts are related but not identical. The essay should not replace the Codex; the Codex should not be used as proof of the essay. They are companion routes into the same threshold problem.

## What this work is not

This work is not a doctrine, school, therapy, spiritual instruction, technical AI-safety specification, software model, AI agent protocol, or executable system. It does not ask for belief, discipleship, or institutional allegiance.

The machine-facing language is structural, not a claim of machine consciousness. The mythic language is symbolic, not literal cosmology. The comparative references are interlocutors, not authorities recruited to validate the work.
