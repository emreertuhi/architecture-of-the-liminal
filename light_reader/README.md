# Light Reader

**Zenodo DOI:** <https://doi.org/10.5281/zenodo.20547058>

The light-reader route gives a lower-friction entrance into *The Architecture of the Liminal*. These files do not replace the companion essay or the Full Codex. They are orientation texts: short reader routes that preserve the core mechanism without turning the work into a checklist, doctrine, or self-help method.

## Files

- `public_companion__the_architecture_of_the_liminal.md` / `.pdf`  
  A public-facing orientation to the whole project, its routes, and its key terms.

- `threshold__human_first_route.md` / `.pdf`  
  A human-first route through the threshold problem: pre-action capture, living brake, body, room, founder entropy, and repair.

- `covenant__machine_facing_route.md` / `.pdf`  
  A machine-facing route about assistance without occupation, user-frame laundering, guardrail laundering, completion pressure, tool-use, and threshold slip.

## How to use this folder

Start here if the essay feels too dense or if the Full Codex feels too symbolically charged.

Read `public_companion__the_architecture_of_the_liminal.md` first for the plainest orientation.

Read `threshold__human_first_route.md` if you want the human and somatic route before the machine-facing layer.

Read `covenant__machine_facing_route.md` if you are using AI systems to summarize, review, package, cite, or operationalize the work.

For the analytic framework, read `../academic/philarchive_companion_essay__reconstructive_threshold_philosophy.md`.

For the full literary-philosophical architecture, read `../heavy_reader/full_codex__the_architecture_of_the_liminal.md`.
