## How to read

For the complete literary-philosophical work, start with `heavy_reader/full_codex__the_architecture_of_the_liminal.md`.

For a shorter orientation, use `WHAT_THIS_WORK_IS_FOR.md` and the documents under `light_reader/`.

For academic citation and submission, use `academic/philarchive_companion_essay.md`.
